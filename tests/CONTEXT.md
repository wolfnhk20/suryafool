## Running

```bash
# Without pytest (stdlib-only runner — the default in this repo)
python -m tests.test_phase2_core

# With pytest (if installed)
python -m pytest tests/test_phase2_core.py -q
```

The file is pytest-collectable (`Test*` classes, `test_*` methods) but the
`__main__` runner means it works in this repo even though pytest isn't a
dependency.

## Rules

- Tests must be deterministic (fixed seeds only).
- Tests must not touch real hardware or LLM providers.
